**Archivos Disponibles**

clases_dominio.puml / .drawio / .mermaid: Código fuente del Diagrama de Clases del Modelo de Dominio (Agregados: Contrato, Proveedor, Evento, Cotizacion).

secuencia_cu01.puml: Código fuente del Diagrama de Secuencia para el CU-01: Aprobar Cotización y Registrar Anticipo.

secuencia_cu04.puml: Código fuente del Diagrama de Secuencia para el CU-04: Registrar Cancelación de Evento por Inclemencia del Tiempo.

**Instrucciones de Edición y Renderizado**

Para editar o generar nuevamente las imágenes de los diagramas a partir de estos archivos de código:

PlantUML (.puml / .plantuml):

Puedes visualizarlos e irlos editando usando la extensión de PlantUML en Visual Studio Code.

O puedes copiar y pegar el contenido directamente en el editor en línea: PlantText o PlantUML Server.

Mermaid (.mmd / .mermaid):

Copia el código y pégalo en Mermaid Live Editor.

Draw.io (.drawio):

Abre Draw.io / Diagrams.net y selecciona File -> Open From -> Device para cargar el archivo.
